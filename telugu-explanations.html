2. CPython, bytecode and Python Virtual MachineCPython, bytecode, Python VM

ఎందుకు అవసరం?

Python "నెమ్మదిగా" ఎందుకు ఉంటుంది, GIL అంటే ఏమిటి, performance ఎక్కడ పోతుంది అని అర్థం చేసుకోవాలంటే Python లోపల ఎలా పనిచేస్తుందో తెలియాలి. Senior interviews లో ఇది తరచూ అడుగుతారు.

సరళమైన వివరణ

CPython అనేది Python యొక్క official implementation (C భాషలో రాసినది). మీరు python అని run చేసినప్పుడు జరిగేది:

1మీ .py source code ని bytecode గా compile చేస్తుంది (ఇది మిషీన్ కోడ్ కాదు, ఒక మధ్యస్థ రూపం)
2ఆ bytecode ని Python Virtual Machine (PVM) ఒక్కో instruction గా అమలు చేస్తుంది.

PHP లో Zend Engine opcodes ని run చేసినట్టే ఇది.

ఉదాహరణ

import dis

def add(a, b):
    return a + b

dis.dis(add)   # bytecode చూపిస్తుంది
# LOAD_FAST a, LOAD_FAST b, BINARY_OP +, RETURN_VALUE

ఇక్కడ మీ a + b అనేది చిన్న చిన్న bytecode instructions గా మారడం కనిపిస్తుంది. కంపైల్ అయిన bytecode ని Python __pycache__ folder లో .pyc files గా save చేస్తుంది, తద్వారా తర్వాతి run వేగంగా మొదలవుతుంది.

3. Python syntax, indentation and code executionSyntax, indentation (ఖాళీలు), code ఎలా అమలవుతుంది

ఎందుకు అవసరం?

Python లో { } brackets బదులు indentation (ఖాళీలు) తోనే code block నిర్ణయమవుతుంది. తప్పు spacing వల్ల code పని చేయదు లేదా తప్పు ఫలితం వస్తుంది.

సరళమైన వివరణ

ఒక block (if, loop, function) లోని lines అన్నీ ఒకే ఖాళీల సంఖ్యతో (సాధారణంగా 4 spaces) మొదలవ్వాలి. Code పై నుండి కిందికి వరుసగా అమలవుతుంది. # తో comments రాస్తారు.

ఉదాహరణ

age = 20
if age >= 18:
    print("Adult")      # 4 spaces: if లోపల
    print("Can vote")   # ఇదీ if లోపలే
print("Done")           # indentation లేదు: if బయట, ఎప్పుడూ run అవుతుంది

age 20 అయినప్పుడు మొదటి రెండు lines మరియు చివరి line print అవుతాయి. age 10 అయితే "Done" మాత్రమే print అవుతుంది.

సాధారణ తప్పు: tabs మరియు spaces కలపడం, దీనివల్ల IndentationError వస్తుంది. ఎప్పుడూ 4 spaces వాడండి.
4. Variables, identifiers and naming conventionsVariables, పేర్లు పెట్టే నియమాలు

ఎందుకు అవసరం?

డేటాని గుర్తుంచుకోడానికి variables కావాలి. మంచి పేర్లు పెడితే మీ code ని మీరే (లేదా team) 6 నెలల తర్వాత కూడా చదవగలరు.

సరళమైన వివరణ

Python లో variable అంటే ఒక value కి పెట్టిన పేరు (label). PHP లా $ అవసరం లేదు. Identifier అంటే variable/function/class కి మనం పెట్టే పేరు. నియమాలు: అక్షరం లేదా _ తో మొదలవ్వాలి, ఖాళీలు ఉండకూడదు, if, for లాంటి keywords వాడకూడదు. Convention (PEP 8): variables మరియు functions కి snake_case, classes కి PascalCase, constants కి UPPER_CASE.

ఉదాహరణ

user_name = "Naveen"      # snake_case variable
MAX_RETRIES = 3           # constant (మార్చకూడదు అనే సంకేతం)

class OrderService:       # PascalCase class
    pass

2name = "x"               # ❌ తప్పు: అంకెతో మొదలు కాకూడదు
5. Dynamic typing and strong typingDynamic typing మరియు strong typing

ఎందుకు అవసరం?

Python లో type ముందే declare చేయనవసరం లేదు, కానీ type పూర్తిగా పట్టించుకోదు అని కాదు. ఈ తేడా తెలియకపోతే runtime bugs వస్తాయి.

సరళమైన వివరణ

Dynamic typing: variable కి type run అయ్యేటప్పుడు value ని బట్టి నిర్ణయమవుతుంది, అదే variable కి తర్వాత వేరే type value ఇవ్వొచ్చు. Strong typing: Python అనుకోకుండా types ని కలపదు. PHP లో "5" + 3 = 8 అవుతుంది (weak), కానీ Python లో error వస్తుంది.

ఉదాహరణ

x = 10          # int
x = "hello"     # ఇప్పుడు str: dynamic typing, ఇది సరే

"5" + 3         # ❌ TypeError: strong typing, Python కలపదు
int("5") + 3    # ✅ 8: మనమే స్పష్టంగా convert చేయాలి
6. Mutable and immutable objectsమార్చగలిగే / మార్చలేని objects

ఎందుకు అవసరం?

ఒక function లో list ని మార్చితే బయట ఉన్న original కూడా మారిపోతుంది. ఇది Python లో అత్యంత సాధారణ bug లలో ఒకటి. దీన్ని అర్థం చేసుకోవాలంటే mutable/immutable తెలియాలి.

సరళమైన వివరణ

Immutable: సృష్టించాక మార్చలేం (int, float, str, tuple, bool). మార్చినట్టు కనిపిస్తే నిజానికి కొత్త object తయారవుతుంది. Mutable: అదే object ని మార్చొచ్చు (list, dict, set). Variables ఒకే object ని చూపిస్తే (reference), ఒకరు మార్చితే అందరికీ కనిపిస్తుంది.

ఉదాహరణ

a = [1, 2, 3]
b = a            # b కూడా అదే list ని చూపిస్తుంది (copy కాదు)
b.append(4)
print(a)         # [1, 2, 3, 4]  ← a కూడా మారింది!

s = "abc"
s[0] = "x"       # ❌ TypeError: str immutable

c = a.copy()     # ✅ నిజమైన copy కావాలంటే
సాధారణ తప్పు: function లో default argument గా def f(x=[]) వాడటం. ఆ list అన్ని calls లో share అవుతుంది.
7. Integers, floats, strings and booleansప్రాథమిక data types

ఎందుకు అవసరం?

ఏ program అయినా ఈ నాలుగు ప్రాథమిక types తోనే మొదలవుతుంది: సంఖ్యలు, దశాంశాలు, text, true/false.

సరళమైన వివరణ

int పూర్ణ సంఖ్యలు (Python లో size limit లేదు), float దశాంశ సంఖ్యలు, str text (single లేదా double quotes), bool True/False. Floats లో చిన్న precision తేడాలు ఉంటాయి, కాబట్టి డబ్బు లెక్కలకు Decimal వాడండి.

ఉదాహరణ

count = 5                 # int
price = 99.99             # float
name = "Naveen"           # str
is_active = True          # bool

print(0.1 + 0.2)          # 0.30000000000000004 (float precision)
print(f"Hi {name}, you have {count} items")   # f-string
8. Type conversion and type checkingType మార్చడం మరియు తనిఖీ చేయడం

ఎందుకు అవసరం?

User input, API responses, files నుండి వచ్చే data తరచూ text (str) గానే వస్తుంది. లెక్కలు చేయాలంటే సరైన type కి మార్చాలి.

సరళమైన వివరణ

int(), float(), str(), bool() తో convert చేస్తారు. Type తెలుసుకోడానికి type(x), మరియు సరైన పద్ధతిలో తనిఖీకి isinstance(x, int). Convert కుదరకపోతే ValueError వస్తుంది కాబట్టి try/except వాడండి.

ఉదాహరణ

age_text = "25"
age = int(age_text)             # 25 (int)
print(isinstance(age, int))     # True

try:
    n = int("abc")
except ValueError:
    print("సంఖ్య కాదు")          # ఇది print అవుతుంది
9. Operators and operator precedenceOperators మరియు వాటి ప్రాధాన్యత

ఎందుకు అవసరం?

లెక్కలు, పోలికలు, conditions అన్నీ operators తోనే. Precedence (ఏది ముందు లెక్కవుతుంది) తెలియకపోతే ఫలితం తప్పుగా వస్తుంది.

సరళమైన వివరణ

Arithmetic: + - * / // % ** (// పూర్తి భాగం, % మిగిలినది, ** power). Comparison: == != < >. Logical: and or not. ప్రాధాన్యత క్రమం సుమారుగా: ** → * / // % → + - → comparison → not → and → or. సందేహం ఉంటే brackets ( ) వాడండి.

ఉదాహరణ

print(2 + 3 * 4)       # 14  (ముందు 3*4)
print((2 + 3) * 4)     # 20  (brackets ముందు)
print(7 // 2, 7 % 2)   # 3 1
print(2 ** 3)          # 8
print(True or False and False)   # True  (and ముందు, తర్వాత or)
10. Conditional statements: if, elif, elseషరతులు (conditions)

ఎందుకు అవసరం?

Program పరిస్థితిని బట్టి వేర్వేరు నిర్ణయాలు తీసుకోవాలి. ఉదా: user admin అయితే ఒక పేజీ, లేకపోతే ఇంకొకటి.

సరళమైన వివరణ

if షరతు true అయితేనే ఆ block run అవుతుంది. elif (PHP లో elseif) మరిన్ని షరతులకు, else ఏదీ కాకపోతే. Python లో falsy values: 0, "", [], {}, None, False; మిగతావన్నీ truthy.

ఉదాహరణ

marks = 72
if marks >= 90:
    grade = "A"
elif marks >= 60:
    grade = "B"      # ఇది ఎంచుకోబడుతుంది
else:
    grade = "C"
print(grade)         # B

items = []
if not items:
    print("Cart ఖాళీ")   # empty list falsy
11. Loops: for, while, break, continue, passLoops (పునరావృతం)

ఎందుకు అవసరం?

వేల records ని ఒకదాని తర్వాత ఒకటి process చేయాలంటే (ఉదా: ప్రతి document ని embed చేయడం) loops తప్పనిసరి.

సరళమైన వివరణ

for ఒక collection లోని ప్రతి item కి run అవుతుంది. while షరతు true ఉన్నంత వరకు. break loop ని వెంటనే ఆపుతుంది, continue ప్రస్తుత round ని వదిలి తర్వాతిదానికి వెళ్తుంది, pass ఏమీ చేయదు (ఖాళీ block కి placeholder).

ఉదాహరణ

for n in range(1, 6):
    if n == 2:
        continue      # 2 ని వదిలేయి
    if n == 5:
        break         # 5 వద్ద ఆపేయి
    print(n)          # 1, 3, 4

count = 3
while count > 0:
    print(count)      # 3, 2, 1
    count -= 1
సాధారణ తప్పు: while లో condition మారే statement మరచిపోవడం → infinite loop.
12. List comprehensions and conditional comprehensionsచిన్న రూపంలో list తయారీ

ఎందుకు అవసరం?

Data ని filter/transform చేయడం AI/data work లో నిరంతరం జరుగుతుంది. Comprehension తో 4-5 lines కోడ్ ఒక్క line లో, చదవడానికి సులభంగా రాయొచ్చు.

సరళమైన వివరణ

రూపం: [expression for item in collection if condition]. PHP లో array_map + array_filter కలిపి చేసే పనిని ఇది ఒక్కసారే చేస్తుంది.

ఉదాహరణ

# సాధారణ loop
squares = []
for n in range(5):
    squares.append(n * n)

# comprehension తో (అదే ఫలితం)
squares = [n * n for n in range(5)]            # [0, 1, 4, 9, 16]

# conditional: సరి సంఖ్యల squares మాత్రమే
even_sq = [n * n for n in range(10) if n % 2 == 0]   # [0, 4, 16, 36, 64]
13. Match-case statementsmatch-case (Python 3.10+)

ఎందుకు అవసరం?

చాలా elif లు వరుసగా రాయడం కంటే, ఒక value ని అనేక pattern లతో పోల్చడానికి match-case స్పష్టంగా ఉంటుంది. Commands, API event types handle చేయడానికి ఉపయోగకరం.

సరళమైన వివరణ

PHP/JS లోని switch లాంటిది, కానీ శక్తివంతమైనది: tuples, lists, dicts నిర్మాణాన్ని కూడా match చేయగలదు. _ అంటే "మిగతావన్నీ" (default). ఇది Python 3.10 లేదా అంతకంటే పైన మాత్రమే పనిచేస్తుంది.

ఉదాహరణ

def handle(command):
    match command:
        case "start":
            return "Starting..."
        case "stop" | "quit":      # రెండిట్లో ఏదైనా
            return "Stopping..."
        case ["move", x, y]:       # list structure match
            return f"Move to {x},{y}"
        case _:
            return "Unknown"

print(handle(["move", 3, 4]))      # Move to 3,4
14. Input and output operationsInput / Output (ఇన్‌పుట్, అవుట్‌పుట్)

ఎందుకు అవసరం?

Program user నుండి లేదా files నుండి data తీసుకోవాలి, ఫలితాన్ని చూపించాలి లేదా save చేయాలి. Logs, scripts, CLI tools అన్నింటికీ ఇది ఆధారం.

సరళమైన వివరణ

print() స్క్రీన్‌పై చూపిస్తుంది. input() user టైప్ చేసిన దాన్ని ఎప్పుడూ str గా ఇస్తుంది. Files కోసం open() ని with తో వాడండి, అప్పుడు file దానంతట అదే close అవుతుంది.

ఉదాహరణ

name = input("మీ పేరు: ")
age = int(input("వయసు: "))       # input str, అందుకే int() తో మార్చాం
print(f"{name}, వచ్చే ఏడాది మీకు {age + 1}")

# file కి రాయడం
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Hello Python\n")

# file చదవడం
with open("notes.txt", encoding="utf-8") as f:
    print(f.read())
సాధారణ తప్పు: input() ఫలితాన్ని నేరుగా సంఖ్యలా వాడటం, ఇది str కాబట్టి లెక్కలు తప్పు అవుతాయి లేదా error వస్తుంది.
